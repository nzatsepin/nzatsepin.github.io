Resources

Software, courses, data archives and references for serial crystallography.

Our software

  • DatView - software for exploring very large serial crystallography datasets & much more. Download, tutorial, manual and update notes on the DatView page. Code: github.com/nzatsepin/DatViewCL (2019 version: nstander/DatView). Please cite if used for your publications.
  • SPIND - software for auto-indexing sparse patterns in serial 'snapshot' crystallography. Code: github.com/LiuLab-CSRC/SPIND. Read about SPIND: Chufeng Li et al. 2019 IUCrJ 6, 72-84.
  • Hit finding - Python-based EZ-Hit-Finding suite.
  • GitHub - github.com/nzatsepin

In 2019 we ran a mini-workshop on sample delivery options for protein microcrystals at the BioXFEL 6th annual conference, which Nadia co-chaired with Prof. Brenda Hogue (ASU).

Data archives

  • CXIDB - Coherent X-ray Imaging Data Bank - archival for experimental data (lots from XFELs). Recent submissions include scripts for reproducing published results.
  • BioXFEL beamtime archive - all XFEL and synchrotron serial crystallography beamtimes from 2009 until now. BioXFEL collaborations only, since 2013. (Public version of archive seems to have moved but might be searchable on www.bioxfel.org.)

Serial crystallography data analysis software

  • CrystFEL - software suite for serial crystallography with an FEL (or synchrotron or any serial crystallography), the development of which is led by Thomas White at CFEL, DESY. It is the first and most cited serial crystallography data analysis software. No programming expertise needed; very well documented & supported; under constant development. It has been used for almost a decade of XFEL serial femtosecond crystallography and serial millisecond crystallography at synchrotron sources.
  • CrystFEL calls indexing modules for high-throughput autoindexing: MOSFLM, DirAx, XDS, felix, TakeTwo, SPIND (Chufeng's sparse indexer, currently interfaced with CrystFEL only through the version of SPIND on the SPIND github page), asdf (CrystFEL's internal algorithm) and, since CrystFEL 0.8.0, Xgandalf.
  • Cheetah - development led by Anton Barty, CFEL, DESY. A set of programs for processing serial diffraction data from free electron laser sources, which enable taking home only the data with meaningful content. Barty et al., J Appl Crystallogr 47, 1118-1131 (2014).
  • OnDA - Online Data Analysis and Feedback for Serial X-Ray Imaging. Development led by Valerio Mariani at CFEL, DESY.
  • cctbx.xfel - need to know some python. Nick Sauter, Aaron Brewster et al.
  • nXDS - described here and demonstrated on synchrotron serial crystallography in Kovacsova et al. (2017), IUCrJ 4, 400-410. Wolfgang Kabsch, Kay Diederichs.
  • cppxfel - paper; can only index with TakeTwo or the indexing tool from DIALS. Developer: Helen Ginn.
  • psana - Linac Coherent Light Source data analysis. Damiani et al., J. Appl. Cryst. 49, 672-679 (2016).
  • CSPAD Mask Maker - written by Andrew Morgan at CFEL, DESY. Very handy tool for making masks for the CSPAD.
  • This special issue of J. Appl. Cryst. has some extra tools that will be handy. As far as I know, all tools designed for XFEL serial crystallography should work for serial synchrotron data too, so don't ignore papers with the "XFEL" clickbait titles. They just get published more rapidly :)
  • Computational Crystallography Newsletter

Radiation damage

  • Radiation damage in macromolecular crystallography - our educational page.
  • FreeDam (Free Electron Laser Damage Simulation Database) - an online resource for damage simulations of various materials when exposed to an intense X-ray free electron laser pulse. The simulations are made with a non-LTE plasma software. Olof Jönsson et al. (2018) High Ener. Dens. Phys. and Scott, H. A. (2001) J. Quant. Spectrosc. Radiat. Transf. 71:689.
