MX3 SSX scan planner

How to use
  1. Choose the plate and sample shape. For an irregular region, select Freehand, load an image if available, check its scale (µm per pixel, image width or Calibrate), then draw one or more regions.
  2. Set the beam FWHM, scan mode (fly or step), spacing and timing.
  3. The planner covers the sample with vertical-column grids: each within the frame limit and fast-scan range, never stacked vertically. “Grid splitting” trades off-sample frames against the number of grids.
  4. Zoom in to inspect beam footprints, frame start/stop ticks, overhangs and scan direction; hover a table row to highlight its grid.
  5. Copy the start-position table. Orange boxes are warnings; the blue box is derived information. Hover ? for definitions. Tooltips flag defaults to check against current beamline values.

Grid start positions

Start = centre of the first data frame (fly) or point (step) in each grid’s top-right column; in fly mode the goniometer begins one overhang above it. Every grid spans the full sample height of its columns, so grids are never stacked vertically and overhangs never cross collected regions. Frame size, acceleration, overheads and fast-scan ranges are defaults; check them against current beamline values.
